# GameDev.tv: Godot 4 C# Action Adventure: Build your own 2.5D RPG

This folder is for [Godot 4 C# Action Adventure: Build your own 2.5D RPG](hhttps://gamedev.tv/courses/godot-c-action-adventure), a paid course on [GameDev.tv](gamedev.tv). The total course length is appoximately 14.5 hrs hours long and covers how to program a 2.5 Action RPG game using C# in Godot. 

The Dungeon RPG folder is were all Godot course work will be stored. Any subquent folder will be me taking the things learned in the course and applying them to an indepent project.
