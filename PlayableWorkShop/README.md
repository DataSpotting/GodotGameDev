# Playable Workship YouTube Course

The purpose of this repository is to strcture Godot game development learning for myself and keep a running history of various learning projects. This folder is for [How to make your first Video Game Playable Workshop](https://www.youtube.com/playlist?list=PLqc8_xgj1YwOzMo5slXfR3wXxYRxgnwun), a free YouTube course. The total course length is appoximately 5 hours long and covers the basic of game development with Godot and it's scripting language GDScript. 

In addition to the video turtorial, there are text based guides on their [website](https://playableworkshop.com) where you can download free assets to use to follow their guide as well

## 🎨 Assets 
The assets I'm using for this follow along are not the assets they provide. I wanted to get a feel for assets that I will use in my actual projects. The assets I'm using are Quaternius's [Univeral Animations Library](https://quaternius.itch.io/universal-animation-library) and [Universal Base Characters](https://quaternius.itch.io/universal-base-characters) from itch.io. Both of these assests are free, with pro version avaiable for purchase. Please support the creator if possible 😊
